# MbMoney

แอป Android ต้นแบบสำหรับเก็บข้อมูลการเงินและช่วยวางแผนการออม เขียนด้วย Java และ XML

## AI ฟรี

แอปใช้ **Ollama + qwen2.5:7b ที่รันบนคอมของคุณ** ไม่มี API key ไม่เรียกบริการ AI แบบเสียเงิน และไม่ต้องสมัครแพ็กเกจเพื่อใช้แชต AI คอมต้องเปิดอยู่ขณะใช้งาน แอปไม่ได้รันโมเดลบนมือถือโดยตรง

1. ติดตั้ง Ollama จาก https://ollama.com/download/windows (เครื่องที่ใช้พัฒนาโปรเจกต์นี้มี runtime แบบ portable เตรียมไว้แล้ว)
2. ดับเบิลคลิก `start-free-ai.bat` หรือเปิด PowerShell ในโฟลเดอร์โปรเจกต์ แล้วรัน:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\start-free-ai.ps1
   ```

   ครั้งแรกจะดาวน์โหลดโมเดลลงเครื่อง Script ปิด cloud mode สำหรับเซิร์ฟเวอร์ที่มันเริ่มเอง และใช้พอร์ตเฉพาะของ MbMoney คือ 11435
3. เชื่อมมือถือผ่าน USB เปิด USB debugging และยืนยันคอมบนมือถือ จากนั้นรัน script อีกครั้งเพื่อเชื่อม AI ไปยังมือถือ
4. เปิด MbMoney > Chat > ตั้งค่า AI ใช้ `http://127.0.0.1:11435` และโมเดล `qwen2.5:7b` แล้วบันทึก
5. กรอกค่าใช้จ่าย เป้าหมายออม และจำนวนวัน แอปจะให้ AI เสนอแผนเริ่มต้น จากนั้นคุยต่อได้ เช่น “ช่วยลดค่าใช้จ่ายอาหาร” หรือ “รายได้เดือนละ 25000 บาท”

ถ้าใช้ Android Emulator โดยไม่เชื่อมพอร์ต USB ให้ใช้ `http://10.0.2.2:11435`

ถ้าต้องการใช้ Wi-Fi ในเครือข่ายบ้านเดียวกัน ให้เริ่มเซิร์ฟเวอร์ด้วย `-Lan` แล้วใส่ IP คอมที่ script แสดงในตั้งค่า AI ถ้าเซิร์ฟเวอร์ MbMoney เปิดแบบ localhost อยู่แล้ว ให้ปิด instance นั้นก่อนเริ่มแบบ LAN อาจต้องอนุญาต Windows Firewall สำหรับเครือข่ายส่วนตัว ห้ามเปิดพอร์ตนี้สู่ Internet

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-free-ai.ps1 -Lan
```

## Prompt และข้อมูล

- แก้บทบาทและคำสั่ง AI ได้ที่ `app/src/main/res/raw/mbmoney_system_prompt.txt` แล้ว build แอปใหม่
- Prompt กำหนดให้ตอบภาษาไทย ช่วยออมและจัดงบประมาณ ไม่แต่งรายได้ ไม่รับประกันผล และถามข้อมูลที่ขาด
- แอปคำนวณยอดออมต่อวันเองด้วย BigDecimal แล้วแนบตัวเลขให้ AI พร้อมประวัติสนทนาล่าสุด
- ส่งให้ Ollama เฉพาะข้อความแชต ค่าใช้จ่าย เป้าหมาย และจำนวนวัน ไม่อ่านข้อมูลส่วนตัวจากหน้าประวัติเพื่อส่งให้ AI
- บันทึกข้อมูลการออมและการเชื่อมต่อในเครื่อง ประวัติ AI เก็บเฉพาะระหว่างเปิดหน้าจอ และกู้คืนเมื่อหมุนจอ
- เมื่อเชื่อมต่อไม่ได้ แอปแสดงสาเหตุและคืนข้อความให้ส่งซ้ำ ไม่แสดงคำตอบจำลองแทน AI
- การเลือกแพ็กเกจและหน้าชำระเงินเป็นส่วนของต้นแบบเดิม ยังไม่ได้เชื่อมการชำระเงินจริง

## Build และทดสอบ

ใช้ JDK 17 และ Android SDK 34 ตั้งค่า `JAVA_HOME` และ `ANDROID_HOME` ให้ตรงกับเครื่อง แล้วรัน:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease
```

Debug APK ติดตั้งได้จาก `app/build/outputs/apk/debug/app-debug.apk` ส่วน release APK ยังไม่ตั้ง signing สำหรับเผยแพร่ ต้องใช้ keystore ของเจ้าของโปรเจกต์เพื่อเซ็น release เอง ไม่เก็บ keystore ลง repository

`app/release/app-release.apk` เป็นไฟล์รุ่นเดิมที่ติดมากับโปรเจกต์ ไม่ใช่เวอร์ชัน AI ใหม่นี้ ให้ใช้ APK ที่ build จากซอร์สปัจจุบัน ถ้าเครื่องมีแอปเดิมที่เซ็นด้วยคนละกุญแจ Android จะไม่อนุญาตให้อัปเดตทับ ต้องสำรองข้อมูลเดิมก่อนจัดการการติดตั้ง

Unit tests ตรวจการคำนวณ ข้อมูลผิดรูปแบบ การจำกัด endpoint ให้เป็นเครือข่ายส่วนตัว รูปแบบคำขอ Ollama การแนบ prompt และกรณีไม่มีโมเดล/คำตอบผิดรูปแบบ ผลจาก MockWebServer ยืนยัน protocol แต่ไม่ได้ยืนยันคำตอบโมเดลจริงหรือมือถือจริง
